🐾 HPet (에이치펫) - 게임으로 만드는 건강 습관
!HPet Logo/Thumbnail

"나의 건강이 곧 내 펫의 성장!"
HPet은 레트로 다마고치 감성과 AI 기술을 결합하여, 지루한 건강 관리를 즐거운 게임으로 바꿔주는 헬스케어 게이미피케이션(Gamification) 서비스입니다.

---

🌟 프로젝트 소개 (About the Project)
바쁜 현대인들에게 영양제 챙겨 먹기와 바른 자세 유지하기는 알면서도 실천하기 어려운 숙제입니다. HPet은 이 과정을 가상의 펫(HPet)을 키우는 과정과 동기화했습니다. 

유저가 영양제 복용을 인증하고 바른 자세 미션을 수행하면, 펫이 경험치를 얻고 레벨업하며 성장합니다. 매일매일 내 펫을 돌보며, 자연스럽게 나의 건강 습관도 함께 성장시켜 보세요!

---

🚀 주요 기능 (Key Features)
💊 1. AI 기반 영양제 맞춤 추천 및 사진 인증
개인화 추천: 연령, 성별, 주요 건강 고민(피로, 거북목, 눈 피로 등)을 바탕으로 내게 꼭 맞는 영양제를 AI가 추천합니다.
AI 카메라 인증: 오늘 먹을 영양제를 카메라로 촬영하면 AI가 분석하여 복용을 인증하고, 펫의 '성장 포션' 보상을 지급합니다.

🧘‍♀️ 2. 실시간 자세 교정 미니게임
거북목 감지: 웹캠을 통해 실시간으로 사용자의 자세를 인식합니다.
보상형 미니게임: 일정 시간(예: 30초) 동안 바른 자세를 유지하면 보상을 획득합니다. 거북목 자세 감지 시 화면에 경고 알림을 주어 바른 자세를 유도합니다.

🐣 3. 나만의 펫 키우기 & 꾸미기 (다마고치 감성)
성장 시스템: 건강 미션을 달성할 때마다 펫이 경험치를 얻고 진화(레벨업)합니다.
옷장 (Closet): 획득한 보상으로 펫에게 다양한 모자와 악세사리를 입혀 나만의 캐릭터로 커스텀할 수 있습니다.
레트로 UI: 옛날 다마고치 게임기를 연상시키는 모바일 픽셀 프레임 디자인으로 레트로한 재미를 더했습니다.

📅 4. 건강 대시보드 및 리포트
히스토리 캘린더: 매일의 영양제 복용 여부와 자세 교정 미션 성공 기록을 달력에서 한눈에 확인합니다.
주간 달성 리포트: 나의 건강 습관 달성률(영양제 복용률, 바른 자세 유지 등)을 퍼센테이지 통계로 제공합니다.

🛠️ 기술 스택 (Tech Stack)
Frontend
Languages: HTML5, CSS3, Vanilla JavaScript
Fonts & UI: Retro Pixel Font, FontAwesome, 모바일 기기 프레임 레이아웃

Backend & AI (추후 확장 시)
Framework: Java (Spring Boot)
AI / Vision: Vision API (영양제 사진 분석), Pose Detection 모델 (자세 감지 및 거북목 판별)
